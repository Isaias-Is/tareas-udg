# Código para el Proyecto

## ¿Qué se tiene que hacer?
### **Aplicación para la Gestión de Bicicletas en un BiciPuerto**

**Objetivo:**

Desarrollar una aplicación web de gestión de bicicletas basado en un servicio de préstamo de bici pública. El proyecto se realizará individual o en equipos de no más de 3 personas con el objetivo de aplicar los conceptos de programación orientada a objetos, gestión de datos en memoria y en archivos, creación de interfaz web de usuario y trabajo en equipo.

**Descripción:**

El proyecto consiste en crear una aplicación de gestión de bicicletas de un BiciPuerto similar a los sistemas utilizados en programas de alquiler de bicicletas. La aplicación debe permitir a los usuarios agregar bicicletas y mostrar la información de las bicicletas disponibles. Además, se debe de crear una interfaz web de usuario para la manipulación de la información.

**Requisitos:**

1. Crear las siguientes clases en Python:
    - **`Bici`**: Representa una bicicleta con atributos como ID, tiempo de uso en horas y metros recorridos.
    - **`BiciPuerto`**: Administra bicicletas en una lista y proporciona métodos para agregar bicicletas y mostrar bicicletas.
2. Implementar un menú de opciones que permita a los usuarios realizar las siguientes acciones:
    - Agregar una bicicleta, solicitando el ID, tiempo de uso (horas) y metros recorridos.
    - Mostrar en formato tabla la información de las bicicletas agregadas.
3. Crear una interfaz web de usuario que incluya botones, campos de entrada y tablas para mostrar los datos de las bicicletas.
